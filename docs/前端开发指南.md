# 前端代码实时修改指南

## 🚀 实时预览设置

### 方法一：使用 Wails Dev 模式（推荐）

`wails dev` 命令会自动启动前端开发服务器，支持**热模块替换（HMR）**，修改代码后会自动刷新。

#### 启动步骤：

1. **确保项目正在运行**
   ```powershell
   # 如果还没有运行，执行：
   wails dev
   ```

2. **修改前端代码**
   - 打开 `frontend/src/` 目录下的任何 Vue 文件
   - 例如：`frontend/src/App.vue`
   - 或者：`frontend/src/components/stock.vue`

3. **保存文件**
   - 保存后，Vite 会自动检测变化
   - 浏览器/应用窗口会自动刷新显示最新内容

### 方法二：分别启动前后端（高级）

如果需要更精细的控制，可以分别启动：

#### 终端 1：启动前端开发服务器
```powershell
cd frontend
npm run dev
```
前端服务器会在 `http://localhost:5173` 启动

#### 终端 2：启动 Wails 应用（连接到前端服务器）
```powershell
# 在项目根目录
wails dev
```

## 📝 修改前端代码的位置

### 主要文件结构：

```
frontend/src/
├── App.vue              # 主应用组件
├── main.js              # 应用入口
├── style.css            # 全局样式
├── router/
│   └── router.js        # 路由配置
└── components/          # Vue 组件
    ├── stock.vue        # 股票组件
    ├── market.vue       # 市场组件
    ├── settings.vue     # 设置组件
    ├── agent-chat.vue   # AI 聊天组件
    └── ...              # 其他组件
```

### 常用修改场景：

#### 1. 修改样式
- 编辑 `frontend/src/style.css` - 全局样式
- 或在各个 `.vue` 文件的 `<style>` 标签中修改

#### 2. 修改组件
- 编辑 `frontend/src/components/` 下的任何 `.vue` 文件
- 例如修改股票列表：`frontend/src/components/stock.vue`

#### 3. 修改路由
- 编辑 `frontend/src/router/router.js`

#### 4. 修改主应用
- 编辑 `frontend/src/App.vue`

## 🔥 热重载说明

### Vite 热模块替换（HMR）特性：

1. **自动检测文件变化**
   - 保存文件后，Vite 会自动检测
   - 通常在 1-2 秒内完成更新

2. **保持应用状态**
   - 大部分情况下，应用状态会保留
   - 只有修改的组件会重新渲染

3. **快速反馈**
   - 修改后立即看到效果
   - 无需手动刷新

### 如果热重载不工作：

1. **检查前端服务器是否运行**
   ```powershell
   netstat -ano | findstr ":5173"
   ```

2. **检查控制台错误**
   - 查看终端中的错误信息
   - 检查浏览器控制台（F12）

3. **重启开发服务器**
   ```powershell
   # 停止当前进程（Ctrl+C）
   # 重新运行
   wails dev
   ```

## 💡 开发技巧

### 1. 使用浏览器开发者工具
- 在应用窗口中按 `F12` 打开开发者工具
- 可以实时查看 DOM、样式、网络请求等

### 2. 查看终端输出
- Wails 和 Vite 会在终端显示编译信息
- 错误信息会直接显示在终端

### 3. 修改后立即查看
- 保存文件后，等待 1-2 秒
- 应用窗口会自动更新

### 4. 调试技巧
- 使用 `console.log()` 在浏览器控制台输出
- 使用 Vue DevTools 扩展（如果安装了）

## 📋 快速测试

### 测试热重载是否工作：

1. 打开 `frontend/src/App.vue`
2. 找到 `<template>` 部分
3. 添加一行测试文字，例如：
   ```vue
   <template>
     <div>
       <h1>测试热重载 - 修改我！</h1>
       <!-- 原有内容 -->
     </div>
   </template>
   ```
4. 保存文件
5. 观察应用窗口，应该立即看到变化

## ⚠️ 注意事项

1. **Node.js 版本**
   - 当前使用 Node.js v22.8.0
   - Vite 7.2.4 建议使用 22.12.0+
   - 如果遇到问题，考虑升级 Node.js

2. **文件路径**
   - 确保在正确的目录下修改文件
   - 路径：`frontend/src/` 下的文件

3. **语法错误**
   - 如果有语法错误，热重载可能失败
   - 查看终端错误信息并修复

4. **保存文件**
   - 确保文件已保存（Ctrl+S）
   - 某些编辑器需要手动保存
