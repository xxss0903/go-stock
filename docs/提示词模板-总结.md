# 提示词模板 - 文档总结

## 📋 通用总结提示词模板

### 模板1：简洁版总结（适合快速概览）

```
请对以下文档进行总结，要求：
1. 提取核心要点（3-5个）
2. 用简洁的语言概括主要内容
3. 突出关键信息和技术细节
4. 输出格式：使用Markdown格式，包含标题和要点列表

文档内容：
[在此粘贴文档内容]
```

### 模板2：结构化总结（适合技术文档）

```
请对以下技术文档进行结构化总结，要求：
1. **数据来源/技术架构**：列出主要数据源、API接口、技术栈
2. **核心功能**：总结主要功能模块和实现方式
3. **数据流程**：描述数据获取、处理、存储的完整流程
4. **关键代码位置**：标注重要代码文件和函数位置
5. **注意事项**：列出需要注意的问题和限制
6. 使用Markdown格式，保持结构清晰

文档内容：
[在此粘贴文档内容]
```

### 模板3：详细版总结（适合深度分析）

```
请对以下文档进行详细总结，要求：
1. **概述**：用一段话概括文档主题和目的
2. **主要内容**：
   - 数据来源/技术方案
   - 实现方式/架构设计
   - 数据存储/处理流程
   - 关键代码和配置
3. **技术要点**：提取关键技术细节、API接口、数据结构
4. **流程说明**：用流程图或步骤说明数据/业务流程
5. **优缺点分析**：总结方案的优点和潜在问题
6. **使用建议**：提供实际使用时的注意事项
7. 输出格式：使用Markdown，包含代码块、表格、列表等

文档内容：
[在此粘贴文档内容]
```

## 🎯 使用建议

### 选择模板的原则：
- **模板1**：需要快速了解文档大意时使用
- **模板2**：技术文档、架构文档推荐使用
- **模板3**：需要深入分析和全面理解时使用
- **模板4**：股票数据相关文档专用
- **模板5**：需要简短摘要，用于AI上下文时使用

### 自定义提示词技巧：
1. **明确目标**：先确定总结的目的（学习、分享、存档等）
2. **指定格式**：明确要求输出格式（Markdown、表格、列表等）
3. **突出重点**：指定需要重点关注的内容（技术细节、业务流程等）
4. **长度控制**：根据需求指定总结长度（简洁版、详细版）
5. **添加约束**：可以添加"不要包含代码"、"只关注架构"等约束

### 示例：针对当前股票数据文档的完整提示词

```
你是一位技术文档分析师，请对以下股票数据来源与存储分析文档进行总结。

要求：
1. **数据来源部分**：
   - 列出所有数据源（新浪、腾讯、Tushare、东方财富等）
   - 说明每个数据源的用途和支持的市场
   - 标注关键API地址和代码位置

2. **存储方式部分**：
   - 说明数据库类型和配置参数
   - 列出主要数据表及其用途
   - 说明存储策略（异步写入、更新机制等）

3. **数据流程部分**：
   - 用简洁的步骤说明实时数据获取流程
   - 说明基础信息初始化流程
   - 说明K线数据获取流程

4. **技术要点**：
   - 编码转换（GB18030 → UTF-8）
   - 异步写入机制
   - 数据库优化方案（WAL、读写分离）

5. **注意事项**：
   - API限制和频率控制
   - Token配置要求
   - 数据准确性考虑

输出格式：使用Markdown，包含代码引用（使用 startLine:endLine:filepath 格式），保持结构清晰。

文档内容：
[在此粘贴文档内容]
```

## 💡 提示词优化技巧

1. **角色设定**：给AI设定角色（如"技术文档分析师"、"架构师"），提高输出质量
2. **格式要求**：明确要求输出格式，避免格式混乱
3. **长度控制**：根据需求指定字数或段落数
4. **重点突出**：使用加粗、列表等方式强调重点
5. **代码引用**：对于技术文档，要求使用代码引用格式
6. **迭代优化**：根据第一次输出结果，调整提示词进行二次总结
