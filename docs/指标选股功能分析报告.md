# 指标选股功能分析报告

## 一、功能概述

指标选股功能位于市场行情页面的"指标选股"标签页中，允许用户通过自然语言描述选股条件，系统会根据条件筛选出符合条件的A股股票，并展示详细的股票数据。

## 二、核心模块和组件

### 1. 前端组件

**文件位置**: `frontend/src/components/SelectStock.vue`

**主要功能**:
- 提供选股条件输入框
- 显示热门选股策略列表
- 展示选股结果数据表格
- 支持一键关注选中的股票

**关键状态变量**:
```javascript
const search = ref('')           // 选股条件输入
const columns = ref([])          // 表格列定义
const dataList = ref([])          // 选股结果数据
const hotStrategy = ref([])       // 热门策略列表
const traceInfo = ref('')        // 选股条件解析信息
```

**核心函数**:
- `Search()`: 执行选股搜索
- `handleFollow(row)`: 关注选中的股票
- `DoSearch(question)`: 使用热门策略进行选股

### 2. 后端API

**文件位置**: `backend/data/search_stock_api.go`

**核心结构**:
```go
type SearchStockApi struct {
    words string  // 选股条件（自然语言）
}
```

**主要方法**:
- `SearchStock(pageSize int)`: 执行选股搜索，返回符合条件的股票列表
- `HotStrategy()`: 获取热门选股策略列表
- `HotStrategyTable()`: 获取热门策略表格
- `StrategySquare()`: 获取策略广场数据

### 3. AI工具集成

**文件位置**: `backend/agent/tools/choice_stock_by_indicators_tool.go`

**功能**: 作为AI Agent的工具函数，允许AI根据自然语言条件调用选股功能

**工具信息**:
- 工具名称: `ChoiceStockByIndicators`
- 参数: `words` (选股自然语言)
- 返回: Markdown格式的股票数据表格

## 四、数据源

**API来源**: 东方财富选股API

**API地址**:
- 选股搜索: `https://np-tjxg-g.eastmoney.com/api/smart-tag/stock/v3/pw/search-code`
- 热门策略: `https://np-ipick.eastmoney.com/recommend/stock/heat/ranking`

**API特点**:
- 支持自然语言选股条件
- 返回丰富的股票指标数据
- 支持多维度筛选（技术指标、财务指标、资金流向等）
- 需要配置 `qgqp_b_id`（东财用户标识）才能使用

**配置要求**:
- 需要在系统设置中配置"东财唯一标识"（qgqp_b_id）
- 获取方式：打开浏览器访问东财网站，按F12打开开发人员工具->网络面板，随便点开一个请求，复制请求cookie中qgqp_b_id对应的值

## 五、返回数据字段说明

### 基础字段
- `SECURITY_CODE`: 股票代码
- `SECURITY_SHORT_NAME`: 股票名称
- `MARKET_SHORT_NAME`: 市场简称（SH/SZ/BJ）

### 技术指标字段（动态）
根据选股条件的不同，返回的字段会动态变化，可能包括：
- 价格相关: 收盘价、开盘价、最高价、最低价
- 技术指标: MACD、RSI、KDJ、BOLL、MA均线等
- 成交量: 成交量、成交额、换手率、量比
- 资金流向: 主力净流入、北向资金等
- 财务指标: 市盈率、市净率、净利润增长率等

### 时间维度字段
部分指标可能包含多个时间维度（如：当日、3日、5日、10日等）

## 九、在app.go中的API绑定

**文件位置**: `app_common.go`

```go
// SearchStock 指标选股
func (a *App) SearchStock(words string) map[string]any {
    return data.NewSearchStockApi(words).SearchStock(5000)  // 最多返回5000只股票
}

// GetHotStrategy 获取热门选股策略
func (a *App) GetHotStrategy() map[string]any {
    return data.NewSearchStockApi("").HotStrategy()
}
```

**注意**: 
- `SearchStock` 默认返回最多5000只股票
- 这些方法通过Wails自动绑定到前端，前端可以通过 `wailsjs/go/main/App` 模块调用

## 十、使用建议

### 1. 在复盘中使用
- 记录每日使用的选股条件
- 保存选股结果，便于后续分析
- 将选股结果与当日涨停跌停板块进行对比分析

### 2. 在自选中使用
- 将选股结果批量添加到自选
- 按选股条件创建分组
- 跟踪选股结果的表现

### 3. 与AI复盘结合
- AI可以调用选股工具进行智能选股
- 将选股结果纳入AI分析范围
- 生成包含选股建议的复盘报告

## 十一、注意事项

1. **API限流**: 同花顺问财API可能有访问频率限制
2. **数据格式**: 返回的列和数据是动态的，需要根据实际返回结构处理
3. **股票代码格式**: 需要转换为系统内部格式（如：SZ000001 -> sz000001）
4. **数据时效性**: 选股结果是实时数据，建议在复盘时保存快照

## 十二、扩展建议

1. **保存选股历史**: 在复盘记录中保存选股条件和结果
2. **选股回测**: 记录选股结果，跟踪后续表现
3. **批量操作**: 支持将选股结果批量添加到自选或分组
4. **条件模板**: 保存常用的选股条件作为模板
5. **结果导出**: 支持将选股结果导出为Excel或CSV
