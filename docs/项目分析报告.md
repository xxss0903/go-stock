# go-stock 项目分析报告

## 📋 项目概述

**项目名称**: go-stock  
**项目类型**: 基于大语言模型的AI赋能股票分析桌面应用  
**技术栈**: Go + Vue.js + Wails v2  
**开发平台**: Windows 10+ (主要), macOS, Linux

### 项目简介
go-stock 是一个基于 Wails 框架和 NaiveUI 开发的股票分析工具，结合 AI 大模型提供智能股票分析功能。支持 A股、港股、美股，提供市场整体/个股情绪分析、K线技术指标分析等功能。

## 🏗️ 项目架构分析

### 1. 技术架构

#### 后端 (Go)
- **框架**: Wails v2.11.0
- **Go 版本要求**: Go 1.25.0
- **主要依赖**:
  - `github.com/wailsapp/wails/v2` - Wails 框架
  - `github.com/glebarez/sqlite` - SQLite 数据库
  - `github.com/chromedp/chromedp` - 浏览器自动化（数据爬取）
  - `github.com/cloudwego/eino` - AI 模型集成（支持 OpenAI、DeepSeek、Ollama 等）
  - `github.com/go-resty/resty/v2` - HTTP 客户端
  - `github.com/robfig/cron/v3` - 定时任务
  - `gorm.io/gorm` - ORM 框架

#### 前端 (Vue.js)
- **框架**: Vue 3.5.17
- **构建工具**: Vite 7.2.4
- **UI 框架**: Naive UI 2.43.2
- **主要依赖**:
  - `vue-router` - 路由管理
  - `echarts` - 图表库
  - `tdesign-vue-next/chat` - 聊天组件
  - `md-editor-v3` - Markdown 编辑器

### 3. 核心功能模块

#### 3.1 股票数据管理
- **股票基础信息**: 支持 A股、港股、美股基础数据管理
- **实时行情**: 实时获取股票价格、成交量等数据
- **K线数据**: 支持日K、分时图等K线数据获取
- **资金流向**: 股票资金流向分析

#### 3.2 AI 分析功能
- **多模型支持**: 
  - OpenAI (GPT 系列)
  - DeepSeek (deepseek-reasoner, deepseek-chat)
  - Ollama (本地模型)
  - LMStudio (本地模型)
  - AnythingLLM (知识库)
  - 硅基流动、火山方舟等聚合平台
- **智能选股**: 基于自然语言的股票筛选
- **技术指标分析**: MACD、RSI、KDJ、BOLL 等
- **情绪分析**: 市场/个股情绪分析
- **研究报告**: 获取机构/券商研究报告

#### 3.3 市场资讯
- **财联社电报**: 实时市场资讯
- **新浪财经**: 财经新闻
- **TradingView**: 全球市场资讯
- **AI 总结**: 市场资讯 AI 分析和总结

#### 3.4 监控与提醒
- **价格监控**: 实时监控股票价格变化
- **涨跌报警**: 涨跌幅达到阈值时提醒
- **钉钉通知**: 支持钉钉消息推送
- **系统托盘**: Windows 系统托盘集成

#### 3.5 数据管理
- **自选股管理**: 股票分组、排序、成本价设置
- **基金监控**: 基金净值、估值监控
- **历史记录**: AI 分析结果保存

## 🚀 运行步骤

### 步骤 1: 安装 Go 环境
1. 访问 https://go.dev/dl/ 下载 Go 1.25.0 或更高版本
2. 安装并配置环境变量 `GOPATH` 和 `PATH`
3. 验证安装: `go version`

### 步骤 2: 安装 Wails CLI
```bash
go install github.com/wailsapp/wails/v2/cmd/wails@latest
```

### 步骤 3: 安装 Go 依赖
```bash
go mod download
```

### 步骤 4: 开发模式运行
```bash
# 方式 1: 使用 Wails CLI
wails dev

# 方式 2: 分别启动前后端
# 终端 1: 启动前端开发服务器
cd frontend
npm run dev

# 终端 2: 启动后端
wails dev
```

### 步骤 5: 构建生产版本
```bash
# Windows
wails build --clean --platform windows/amd64

# macOS
wails build --clean --platform darwin/universal

# Linux
wails build --clean --platform linux/amd64
```

## 🔍 项目特点分析

### 优势
1. **跨平台支持**: Windows、macOS、Linux 多平台
2. **AI 集成丰富**: 支持多种 AI 模型和平台
3. **功能完整**: 涵盖股票数据、分析、监控、资讯等全流程
4. **实时性强**: 支持实时行情、实时资讯推送
5. **用户体验好**: 系统托盘、通知提醒、暗色主题等

### 技术亮点
1. **Wails 框架**: 使用 Go + Web 技术栈构建原生桌面应用
2. **AI 工具函数**: 集成多个 AI 工具函数，增强分析能力
3. **定时任务**: 使用 cron 实现定时数据更新和分析
4. **数据缓存**: 使用 freecache 提高性能
5. **多数据源**: 整合 Tushare、爬虫等多种数据源

### 潜在问题
1. **Go 版本要求高**: 需要 Go 1.25.0，可能部分环境不支持
2. **Node.js 版本警告**: 当前 Node.js v22.8.0 不完全符合要求（需要 22.12.0+）
3. **依赖外部服务**: 依赖 Tushare、GitHub API 等外部服务
4. **数据爬取**: 部分功能依赖网页爬取，可能受网站结构变化影响
